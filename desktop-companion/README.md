# Discord companion

Show your Plural Star fronters in your Discord activity. No PluralKit account or sync is needed.

1. Enable cloud sync in Plural Star and let it upload your data. Note your cloud password and relay URL in its cloud settings.
2. Download your computer's build from the [desktop releases](https://github.com/sparklecatdev/plural-star-mods/releases) and extract it. Run `Install-Linux.sh`, `Install-macOS.command`, or `Install-Windows.ps1` for your system, then find Sparklecat Discord Companion in your application menu. Run the installer again to replace an existing installation; your settings are kept. Windows and Linux downloads support 64-bit systems; Linux also has an ARM64 build. Choose the Intel or Apple silicon build for your Mac.
3. Open the Discord desktop app and enable activity sharing in Discord.
4. Enter your Plural Star cloud password and relay URL. Enter a relay token only if your relay uses one. Select Start.

The companion reads the encrypted cloud save directly and displays primary and co-fronting member names in Discord. These names are visible to others through your Discord activity; check Discord's privacy settings before starting. It checks every 30 seconds and clears the activity when stopped or a refresh fails. Plural Star must sync changes to the cloud, and your computer must be awake with Discord and the companion running.

Select **Remember password securely** to store the password and relay token in your operating system’s credential store. With saved credentials the companion connects automatically on launch. Select **Start when I sign in** to launch at login, and choose whether closing quits, minimizes, or hides it in the system tray. Choose a window and tray title and a custom image for the window and tray icon, or restore the default icon. Select **Save settings** to apply changes. Your system may keep its installed application or dock icon unchanged. Linux requires an unlocked Secret Service keyring and a desktop tray; tray support varies on Wayland. The companion registers a linked device in your cloud account; you can remove it from Plural Star's linked devices list. Its local device ID is saved so it can reuse the same device slot. The default Plural Star relay uses HTTP, which exposes cloud authentication to the network even though vault data is encrypted. Use an HTTPS relay where possible.

To manage the companion from your phone, enable **Sync appearance and startup settings with Plural Star** in the companion and save. On the patched app, enable **Sync mod preferences** in sparklecat's mods, then use **Discord companion** there. Both devices must use the same cloud account. The companion checks for settings changes every 30 seconds while running. The title, icon, startup and close behavior sync; passwords, relay tokens and other credentials do not. Changes to the same settings made concurrently use the last saved version.

The downloads do not require Python. macOS and Windows may warn about the unsigned application. On macOS, open it from Finder and allow it in Privacy & Security if needed. On Linux, the build requires a graphical desktop and is built on Ubuntu 22.04. Flatpak and Snap Discord are supported when their IPC socket is accessible.

Installed builds check for a newer desktop release at launch and install verified updates automatically. Extracted builds that have not been installed do not update themselves. On Windows, if PowerShell blocks the installer, run it from a PowerShell window with `powershell -ExecutionPolicy Bypass -File .\Install-Windows.ps1`.

To run from source, install Python 3 with Tkinter, then use `Start.command` on macOS, `Start.bat` on Windows, or `sh Start.command` on Linux. The launcher installs the required packages on first use.

Customize the Discord presence in **Edit Discord presence**, or from the synced mobile companion settings. Select **Load my fronters** to preview your cloud names, pronouns and first fronter's photo. While the companion is running, names and pronouns refresh automatically. Use `{fronters}` and `{count}`, or `{name}` and `{pronouns}` for the first fronter. Use `{avatar}` in an image field to share the first fronter's public HTTPS photo URL on Discord. Photos stored privately in the encrypted cloud can be shown in the local preview but cannot be sent to Discord as image URLs. Images also accept public URLs or Discord application asset keys; up to two buttons can open web links. Discord controls the application name and icon in its Developer Portal. Selected names, pronouns and image URLs are visible through Discord activity.
